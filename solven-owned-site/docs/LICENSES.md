# License inventory

The owned-site runtime uses only Node.js built-in modules and has no third-party runtime package dependency.

Development/browser verification uses Playwright from the repository root. Its license and transitive dependency notices must be regenerated from the destination lockfile before distribution if test tooling is shipped. The portable runtime bundle does not include `node_modules`, browser binaries or Playwright reports.

Canonical business content and Solven brand assets are project materials, not third-party reusable assets. No stock person image, customer asset or external font is bundled.
