# Owned-site 表示設計 v2

## 目的

Solvenを「中小企業の集客導線と業務改善を、HP・LP・Webアプリから適切に選び、小さく始めて公開後も改善できる会社」と数秒で理解できる表示層にする。技術そのものではなく、相談前後の変化と完成画面を主役にする。

## 視覚方針

- 白と淡い青灰色を主背景にし、濃紺は制作例・Webアプリ料金など意味のある帯に限定する。
- 公式ロゴは`public/assets/solven-logo-symbol.svg`を正本指定SVGからbyte無改変で保持し、header、footer、会社紹介、faviconへ使用する。ファイルSHA-256は`42338a332439a628ca01d52b7c1573593d184dd204274fd556b9b630df486eb5`。
- 公式色は濃紺 `#0B1F35`、青 `#3884D2`、白 `#FFFFFF` の3色だけとする。濃紺は本文・主要CTA・暗色面、青は罫線・選択状態・図形など非文字accent、白は背景・反転文字に使う。
- 可読性のためのneutralは、補助文と入力borderの`#526170`、区切り線の`#D5DEE6`、面を分ける`#F4F7FA`と`#E7EDF3`に限定する。情報階層、入力境界、隣接sectionの識別を色以外の余白・borderと併用し、これらをブランド色として扱わない。
- focusの`#B54708`とerrorの`#9E3427`は状態識別専用のsemantic色であり、公式Brand Kitには含めない。青／白のalpha表現は公式色から派生する装飾に限る。
- 旧表示の`#071B2B`、`#087F89`、`#09A9B4`等は公式色ではなく、公開CSS・favicon・OG画像から除去する。
- 大きな見出し、十分な余白、画面モック、Before／After図解を組み合わせる。同一カードの反復でページを構成しない。
- 装飾用のAI画像、サイバー表現、架空の効果数値、顧客名、口コミは使わない。
- 320pxから横スクロールなしで成立させ、主要CTAの高さを44px以上にする。

## 情報階層

1. ファーストビュー: 正本キャッチコピー、短い提供範囲、無料相談、簡易診断、HP・LP・Webアプリの合成デモ。
2. サービス選択: 顧客の3目的からLP、HP／既存改善、Webアプリへ誘導。
3. 課題と解決: 4種類のBefore／Afterを図解。
4. 制作例: HP、LP、Webアプリを大きな画面デモと短い「課題・対応・向いている企業」で表示。
5. 簡易診断: 既存ロジックと値を維持。
6. 料金: HP・LPの初期費用＋月額24回と、Webアプリの開始価格を別背景で分離。
7. 代表者・会社: 非人物のブランド図形、確認済みの代表者・会社情報、対応姿勢。未確認経歴は追加しない。
8. 問い合わせ: 記入ガイドを先に示し、既存Lead／Consent処理を維持したフォームを並置。

## コンポーネント

- `product-stage`: HPデスクトップ、LPスマートフォン、Webアプリ管理画面を重ねる主役ビジュアル。
- `purpose-route`: 目的、短い説明、推奨入口を1行でつなぐ選択導線。
- `transform-list`: Before、変化、Afterを1組にした図解。スマートフォンではAfterを残して縦積みする。
- `work-story`: 各制作例で説明と画面デモを交互配置する。
- `price-plan`: 正本の初期費用、月額、回数、総額、標準範囲を近接表示する。
- `webapp-plan`: 開始価格、画面・権限目安、有償要件整理を表示する。
- `identity-placeholder`: 公式ロゴと抽象図形だけで構成する非人物の代表者placeholder。
- `contact-guide`: フォーム入力前に必要な情報を3点へ絞る。

## 素材台帳

- 本番表示のHP、LP、Webアプリ、Before／AfterはHTML/CSSで作った説明用デモ。顧客案件画面や個人情報を含まない。
- 代表者写真は使用せず、非人物のブランドplaceholderと確認済み氏名・役職だけを掲載する。
- アイコンは導線矢印と画面構造の最小表現だけを使用する。
- レイアウト検討用の生成画像はローカル専用のgit-ignored領域に置き、本番配信物・commit・外部共有成果物へ含めない。

## 正本・機能境界

- ブランドの正本キャッチコピー、会社情報、価格、標準範囲は`public/data/owned-site.json`から表示する。
- 診断の値、問い合わせfield、内部`lead_id`と公開`receipt_id`の分離、atomic保存、outbox、retry、dead letter、CSRF、rate limit、idempotency、Consent、GA4契約、security headerは表示変更の対象外とする。
- HP・LPの契約条件をWebアプリへ流用せず、両料金体系を明確に分離する。

## 公開前に追加判断が必要な素材

- 代表者の詳細経歴を将来掲載する場合の、Ownerが事実確認した短文。
- 実績掲載を行う場合の顧客許諾済み素材。許諾前はデモ表示を維持する。
